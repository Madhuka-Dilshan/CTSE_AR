### Project Overview

An immersive Augmented Reality (AR) application developed using Unity, featuring an interactive alien character placed within a dark forest environment.

This project demonstrates real-time AR rendering, seamless 3D object integration, and atmospheric scene composition to create a visually engaging AR experience.

### ✨ Key Highlights

🌲 Realistic dark forest environment

👽 Interactive 3D alien model

📱 Real-time AR tracking and rendering

🎮 Built using Unity and C#

🌍 Immersive scene design with lighting and depth effects

### 🛠️ Technologies Used

Unity Engine

C#

AR Foundation

3D Models & Textures

Scene Lighting & Environment Design

### 🎯 Purpose

This project was created to explore Augmented Reality development using Unity, focusing on environment realism, object placement, and interactive AR experiences suitable for mobile platforms.
